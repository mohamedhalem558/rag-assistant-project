# RAG Assistant Project (Graduation Project)

A local Retrieval-Augmented Generation (RAG) backend built with **FastAPI**, **ChromaDB**, **Sentence-Transformers**, and **Ollama (Llama 3)**.

## Project Structure
- `backend/app/api/`: API routes for querying.
- `backend/app/services/`: RAG pipeline and vector search logic.
- `backend/data/`: Vector store database and local knowledge base documents.
